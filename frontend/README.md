# Frontend (AARAMBH)

- React/Next.js + TypeScript UI/presentation layer.
- app/ — routing and page entry points
- modules/ — one folder per major product feature (see modules/<name>/README.md)
- components/, layouts/ — shared/reusable UI
- services/ — shared API client logic
- store/ — global state management
- hooks/, types/, utils/, constants/ — shared frontend utilities
- assets/, styles/, public/ — static resources
