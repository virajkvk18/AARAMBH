# Database Schema Reference

## Entities Overview
- **Users**: Applicants, Department Officers, Admins.
- **Enterprises**: Business profile, PAN/GSTIN, MSME Udyam details.
- **Applications**: Core single-window submissions, CAF data, status lifecycle.
- **Clearances / Approvals**: Per-department sub-clearances, SLA timelines, approval status, certificates.
- **Documents**: Uploaded/DigiLocker documents, verification status, OCR extracted payload.
- **Grievances & Queries**: Officer queries, applicant responses, grievance tickets.
- **Incentive Applications**: Scheme eligibility, claim amounts, disbursement state.
